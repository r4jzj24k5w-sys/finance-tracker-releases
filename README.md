# Finance Tracker — канал сборок

Публичный канал бинарных сборок Finance Tracker для macOS 14+ / Apple Silicon.

[Скачать Finance Tracker 0.3.3, сборка 8](https://raw.githubusercontent.com/r4jzj24k5w-sys/finance-tracker-releases/main/releases/0.3.3/FinanceTracker-0.3.3-macOS.zip). [Изменения и проверки](releases/0.3.3/README.md). [SHA-256](releases/0.3.3/SHA256SUMS.txt).

В 0.3.3 столбики графиков выделяются цветом без точки, с главной убран список операций, добавлен номер договора вклада и его сопоставление с описанием импортируемых операций.

Сборка содержит обновления из приложения и зашифрованную локальную историю базы/PDF. Для перехода с 0.1.0 один раз замените приложение вручную, сохранив папку Application Support/FinanceTracker и ключ Keychain. Затем используйте «Проверить обновления…».

Предварительная сборка подписана ad-hoc, без Apple Developer ID и нотариализации. Полный цикл установки и перезапуска через Sparkle требует ручной приемки.

`appcast.xml` — подписанная Ed25519 лента Sparkle. Подпись архива проверяется до распаковки. Финансовые данные остаются на Mac; в этом репозитории нет баз, документов, ключей или приватного исходного кода.

Архив 0.3.3 находится в `releases/0.3.3/` вместе с контрольной суммой и публичными метаданными. Лента ссылается на файл в `main`: архив и обновленная лента становятся доступны вместе после слияния PR. Предыдущие сборки и записи ленты сохранены.

Автоматические source archives GitHub относятся только к публичному описанию, ленте и бинарным файлам этого репозитория.
