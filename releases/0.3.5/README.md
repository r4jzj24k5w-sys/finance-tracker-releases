# Finance Tracker 0.3.5 (сборка 10)

Исправлена подготовка перезапуска при обновлении из настроек: после сохранения защищенной копии настройки и история закрываются, повторная проверка обновлений блокируется. Сервисные панели на macOS 15.4+ явно разрешают завершение приложения; на более ранних версиях они закрываются заранее.

Первый переход со старой версии может потребовать ручного выхода: исправленный код начинает работать после установки 0.3.5.

База, PDF, ключ Keychain и история сохраняются. Ошибка создания защищенной копии отменяет установку.

Проверки: 103 теста, 101 прошел, 2 пропущены; подпись пакета проверена. Полный цикл замены и перезапуска Sparkle, а также macOS 14–15.3 требуют ручной приемки.

macOS 14+, Apple Silicon. Предварительная сборка подписана ad-hoc, без Developer ID и нотариализации.
