Finance Tracker 0.3.5

Исправлена подготовка перезапуска при обновлении из настроек.

  • После сохранения защищенной копии настройки и история импортов закрываются.
  • Сервисные окна больше не блокируют выход на macOS 15.4+. На более ранних системах они закрываются заранее.
  • Повторная проверка обновлений во время установки недоступна.
  • При ошибке сохранения копии установка отменяется.

Первый переход со старой версии может потребовать ручного выхода: исправление действует после установки 0.3.5.

Проверки: 101 тест прошел, 2 пропущены. Полный цикл Sparkle и macOS 14–15.3 требуют ручной приемки. Предварительная ad-hoc сборка, без Developer ID и нотариализации.
