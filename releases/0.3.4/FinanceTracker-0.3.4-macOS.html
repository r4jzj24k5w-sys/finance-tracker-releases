Finance Tracker 0.3.4

  • Единый пункт «База данных» с вкладками «История», «Резервная копия», «Удаление данных».
  • Полная очистка базы, PDF, черновиков и локальной истории восстановления. Для выполнения введите «УДАЛИТЬ ВСЕ ДАННЫЕ» и нажмите «Подтвердить». Есть кнопка «Отмена».
  • Новая иконка: монеты на темно-сером фоне и зеленая стрелка вверх и вправо.

Очистка необратима через локальную историю. Внешние резервные копии и исходные PDF вне приложения сохраняются. До очистки при необходимости создайте резервную копию.

Сборка 9. macOS 14+, Apple Silicon. Обновление само по себе сохраняет базу и ключи; очистка выполняется только после явного подтверждения. Подпись приложения ad-hoc, без Developer ID и нотариализации.
