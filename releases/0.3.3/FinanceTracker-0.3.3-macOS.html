Finance Tracker 0.3.3

  • На графиках расходов и доходов столбик при наведении выделяется темно-синим без точки.
  • С главной убран список операций; история доступна на странице карты и в аналитике.
  • При добавлении вклада можно указать номер договора. Номер виден на странице вклада и доступен для изменения.
  • При импорте номер договора сопоставляется с описанием операции. Найденный вклад показывается в предпросмотре и карточке операции; собственный перевод подтверждается пользователем.

Совпадения проверяются по полному номеру. При нескольких совпадениях вклад выбирается вручную. Данные и ключи хранилища сохраняются.

macOS 14+, Apple Silicon. Сборка 8. Подпись приложения ad-hoc.
