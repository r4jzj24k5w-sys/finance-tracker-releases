# Finance Tracker 0.3.3 — сборка 8

macOS 14+, Apple Silicon. Публичный канал: finance-tracker-releases.

## Изменения

1. На столбчатых графиках расходов и доходов выбранный день выделяется темно-синим. Подсказка привязана к столбику; точка не рисуется. На линейных графиках точки сохранены.
2. С главной убран блок операций. История доступна на странице карты, в аналитике и в «Требует внимания».
3. В форме добавления вклада и первоначального создания счетов добавлено поле «Номер договора». Оно сохраняется зашифрованным и отображается на странице вклада. Для существующего вклада номер можно указать через «Изменить счет».
4. При импорте номер договора вклада сопоставляется с полным идентификатором в описании операции, включая описание на нескольких строках PDF. Сопоставление работает для пополнений и списаний. Совпадение части более длинного номера не подходит. Пустые и неизвестные договоры не связываются; несколько совпадений показываются для ручного выбора.

При единственном совпадении сохраняется предложенная односторонняя связь с вкладом. Ее видно в предпросмотре импорта и списке операций; карточка операции открывается с выбранным вкладом. Пользователь подтверждает собственный перевод, затем он исключается из доходов и расходов. До подтверждения операция остается неклассифицированной. Операция сохраняется на исходном счете; движение и баланс вклада не создаются автоматически. Повторный импорт не дублирует связь и не переопределяет классификацию пользователя.

Договор из описания операции больше не присваивается банковской карте как ее собственный договор. Схема базы и ключи не меняются: используется существующее необязательное поле договора и модель связей.
