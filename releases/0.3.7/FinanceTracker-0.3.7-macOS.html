Finance Tracker 0.3.7 — исправление чтения отчетов по вкладам

  • Распознается колонка «Сумма операции в валюте договора» в отчетах Т-Банка по вкладам.
  • Сохраняется поддержка отчетов по картам и счетам, проверка реквизитов, знаков сумм и оборотов банка.
  • Договор из описания перевода не подменяет договор выбранного вклада.
