# Finance Tracker 0.5.0

- Приветствие разделено на три шага: знакомство с приложением, выбор темы и создание карт и вкладов. К предыдущему шагу можно вернуться без потери введённых данных.
- Кнопки и индикатор используют выбранную тему. После нажатия «Готово» индикатор заполняется, сменяется галочкой, затем открывается основное окно.
- Линии графиков появляются слева направо, а столбики растут последовательно. Настройка macOS «Уменьшение движения» отключает анимации.
- Кнопка импорта PDF убрана из правого верхнего угла. Импорт доступен в боковой панели, через ⌘I и в разделах операций карты и документов вклада.

Схема хранилища и форматы финансовых данных не изменились. Сборка 15 предназначена для macOS 14 и новее на Apple Silicon.
