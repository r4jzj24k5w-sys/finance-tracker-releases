Finance Tracker 0.6.0

  • Присваивайте категории расходам и сохраняйте локальные правила по продавцам. Перед применением правила к истории приложение показывает совпадения.
  • В «Аналитике» видно, сколько потрачено в каждой категории. Сравнение с предыдущим периодом той же длины доступно, когда выписки полностью покрывают оба периода для одного набора карт.
  • Блок «Какие выписки нужны» на главной показывает пробелы по активным включённым картам за последние 30 завершённых дней. Кнопка рядом с картой открывает импорт с выбранным счётом.
  • При импорте нескольких PDF видны счёт и результат для каждого файла. Ошибку можно посмотреть и повторить обработку отдельного файла.
  • Если хранилище не открылось, на экране запуска можно восстановить данные из `.ftbackup`. Приложение проверяет архив и оставляет исходное зашифрованное хранилище рядом с восстановленным.

Сборка 16 для macOS 14 и новее на Apple Silicon.
