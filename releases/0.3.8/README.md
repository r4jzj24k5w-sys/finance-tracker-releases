# Finance Tracker 0.3.8 · сборка 13

- Обновлены 11 экранов, правая навигация, светлая и тёмная темы.
- На главной общий остаток разбит по картам и вкладам на одну дату.
- В разделе «Вклады» собраны актуальные остатки, контрольные даты и архивные вклады.
- В импорте PDF видны этапы проверки, итоги распознавания и причины блокировки.

На macOS 27.2 прошли 115 тестов из 118, включая Vision OCR. Три теста с приватными банковскими PDF пропущены. На синтетической базе проверены обе темы, импорт PDF, создание и восстановление резервной копии.

macOS 14 и новее, Apple Silicon. Приложение подписано ad-hoc. Канал Sparkle использует подписи Ed25519.
