# Finance Tracker 0.4.0

- Плавающая боковая панель и основные кнопки используют нативный Liquid Glass на macOS 26 и новее. На macOS 14–15 используется полупрозрачный материал SwiftUI.
- При запуске плавно появляются рабочая область и навигация. Карточки и строки операций меняются при прокрутке. При наведении элементы выделяются цветом текущей палитры. Интерфейс учитывает системные настройки уменьшения движения и прозрачности.
- Доступны «Сирень», «Мятная», «Розовая», «Тёмно-синяя», «Голубая», «Тёмно-зелёная», «Оранжевая», «Изумрудная», «Серебро», «Золото» и «Платина». Палитра применяется сразу и сохраняется на этом Mac. Светлый, тёмный или системный режим по-прежнему выбирается отдельно.
- При первом запуске с пустым хранилищем приветственное окно знакомит с возможностями, предлагает цветовую палитру и открывает создание карты или вклада. Можно выбрать «Позже» и в любой момент снова открыть приветствие из настроек.

Схема хранилища и форматы финансовых данных не изменились. Для сборки требуется Xcode 26 или новее; минимальная версия системы для запуска — macOS 14.
