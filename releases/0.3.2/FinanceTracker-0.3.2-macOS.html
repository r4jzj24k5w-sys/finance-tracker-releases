Finance Tracker 0.3.2 — фильтры и массовая классификация.

  • В «Требует внимания» добавлен фильтр «Все / Расход / Пополнение» по направлению банковского движения.
  • Правый клик по транзакции в аналитике открывает меню классификации.
  • Чекбоксы слева позволяют выбрать несколько операций или все показанные строки.
  • Правый клик по отмеченной строке применяет классификацию ко всем выбранным операциям. Неотмеченная строка изменяется отдельно. При смене фильтра скрытые строки исключаются из выделения.

macOS 14+, Apple Silicon. Сборка 7. Схема базы не меняется. Подпись ad-hoc, без Apple Developer ID и нотариализации.
