# Finance Tracker 0.3.2 — сборка 7

macOS 14+, Apple Silicon. [Скачать архив](FinanceTracker-0.3.2-macOS.zip) · [SHA-256](SHA256SUMS.txt) · [Метаданные и подпись](release.json).

## Изменения

1. В «Требует внимания» добавлен фильтр «Все / Расход / Пополнение». Направление определяется знаком банковского движения до классификации; нулевые движения видны в «Все».
2. Правый клик по транзакции в аналитике и списке «Требует внимания» открывает меню классификации.
3. Слева у каждой транзакции появились чекбоксы. Можно выбрать все показанные строки и снять выделение.
4. Правый клик по отмеченной строке позволяет назначить классификацию всему выделению. Правый клик по неотмеченной строке применяется только к ней. При смене поиска, периода или фильтра скрытые строки исключаются из выделения; в аналитике выбор ограничен показанными первыми 1000 строками.

Весь набор сохраняется атомарно, после проверки направлений движения. При ошибке ни одна выбранная операция не изменяется. Свои переводы требуют подтверждения, корректировки — причины. Примечания сохраняются, каждое решение записывается в историю. Список, счетчик и аналитика обновляются после сохранения. Схема хранилища не меняется.

## Проверки

- 85 тестов: 84 успешно, 1 пропущен (отсутствуют приватные банковские PDF), ошибок нет. Vision OCR успешно проверен вне песочницы.
- Семь новых тестов проверяют направления, область действия правого клика, сброс скрытого выделения, атомарность смешанного набора и устаревших ID, сохранение в зашифрованном хранилище, историю решений, пересчет расходов, причины корректировок и подтверждение переводов.
- В отдельной QA-сборке с синтетическими данными проверены фильтры, чекбоксы, одиночное и массовое контекстное меню в аналитике и «Требует внимания», классификация двух расходов, классификация пополнения, обновление счетчика 3 → 1 → 0 и пересчет аналитики.
- Проверены версия 0.3.2 / сборка 7 внутри ZIP, подпись приложения и вложенных компонентов после распаковки, подписи Ed25519 архива и ленты. Пять предыдущих записей ленты сохранены.

Подпись приложения ad-hoc; Developer ID и нотариализация не настроены. Минимальная macOS 14 и полный цикл замены/перезапуска через Sparkle отдельно не проверялись.
