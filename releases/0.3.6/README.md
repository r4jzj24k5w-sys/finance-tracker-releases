# Finance Tracker 0.3.6 (сборка 11)

Добавлены отчеты о движении средств для вкладов. PDF можно выбрать при создании вклада или позже кнопкой «Добавить отчет» на его странице. После сохранения счета откроется проверка отчета.

На странице вклада доступны проведенные отчеты, просмотр оригиналов PDF и классификация операций. Сохраняются проверка банковских оборотов, сверка счета и договора, черновики и защита от повторного проведения. Поддерживается существующая форма Т-Банка; неизвестные формы блокируются.

Отчет не меняет остаток вклада автоматически. При импорте можно вручную подтвердить остаток на конец дня внутри полного периода отчета. Более позднее значение остается активным; отмена отчета удаляет связанный остаток.

Проверки: 112 тестов, 110 прошли, 2 пропущены (OCR runtime и приватные PDF). Интерфейс создания и импорта проверен на синтетическом PDF в отдельном QA-хранилище. Release-компиляция, подпись пакета и Ed25519 подписи обновления проверены. Реальная форма отчета по вкладу и полный цикл установки/перезапуска Sparkle требуют ручной приемки.

База и ключ Keychain сохраняются. macOS 14+, Apple Silicon. Предварительная сборка подписана ad-hoc, без Developer ID и нотариализации.
